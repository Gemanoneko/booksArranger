# Books Arranger — additive audiobook sources

2026-10-20. Ender source-boundary implementation. This note describes tested source code, not live configuration activation, a canonical QA receipt, release clearance or authorization to relocate media.

## Public contract

`Inventory(database, roots=None, reader=read_metadata, *, audiobook_sources=None, output_root=None)` preserves the exact scalar `roots['Audiobooks']` string as Source 1. Persisted `files.root`, scan jobs/queues, groups, approvals and retirement keys retain their existing identity. Extra roots are separate catalog scopes; matching filenames/tags do not combine their recordings. `groups.render` adds `source_root` only to the response, outside fingerprinted evidence. Existing group IDs/revisions/fingerprints/reviews survive adding Source 2.

`source_config.normalize_sources(roots, audiobook_sources=None, output_root=None)` returns frozen `SourceConfig(audiobook_sources: tuple, audiobook_output_root: str | None)`. `load_source_config(mapping, legacy_roots)` reads additive fields `audiobook_sources` and `audiobook_output_root`; `.to_fields()` returns only those fields for a caller to merge with existing settings. Parsing never writes settings. Source 1 must equal the exact existing root, not a normalized replacement. Paths must be absolute. Duplicate, nested and realpath-alias source roots are refused; sources cannot overlap Ebooks or live inside Podcasts. The intentional existing Podcasts subtree stays separate. Output may be nested inside a source (excluded from discovery), but cannot contain/alias a source or overlap Podcasts/Ebooks. Missing paths are allowed, preserving disconnected-drive configurations.

Inventory exposes `.audiobook_sources`, `.output_root`, `source_roots(label='Audiobooks')`, `all_source_roots()`, `source_root_for_path(path, label='Audiobooks')` and `source_root_for_candidate(id)`. `source_root_for_path` rejects relative/escaped paths and the configured output/Podcasts tree. It resolves source containment; it does not grant deletion authority or prove an arbitrary file belongs to a candidate. Exact candidate membership, revision, source hashes and native boundaries remain downstream requirements. Additional recorded output/recovery/relocation exclusions are applied by scanner admission and candidate source refresh. `.output_root` remains `None` for legacy settings; the integration owner must preserve existing output policy for that case rather than treating `None` as a source path.

`launch('Audiobooks', resume=False)` prepares per-source durable scan state atomically and runs both sources sequentially in one worker. `stop()` also stops roots not yet reached. `launch_source(root, resume=False)` explicitly selects one configured source. `source_status(root)` returns its existing counters/checkpoints; `status('Audiobooks')` aggregates counters and reports `sources: [{source_root, ...status}]` when more than one source exists. Single-source behavior retains its prior status shape. Resume skips already completed roots and resumes saved stopped/offline/failed scopes. Failed enumeration or an unavailable root never establishes deletion: saved rows remain and the scope reports errors/offline.

`rows` and `candidates` cover every configured audiobook source in one SQLite snapshot. `groups.page_sources` groups separately, uses one root-IN query for unfiltered count/page and renders only that page. Search/status/optional IDs share one predicate and total before global pagination. Candidate `source_root` is returned by list, detail and save. `candidate`, `save_candidate` and `refresh_candidate_sources` resolve the exact candidate's source rather than assuming Source 1. Saved queue paths and refresh members cannot cross source boundaries.

Discovery excludes the configured output subtree, Podcasts, symlink/junction children, exact owned temporary/recovery/output paths and `output_relocations.planned_destination` when that optional table/column exists. Configuring an output exclusion does not erase historical catalog evidence or mark its existing rows missing. Existing historical output groups require explicit reconciliation by the publication integration owner; scanner exclusion alone is not that migration. Relocation path exclusion is defensive and reads no evolving relocation state/receipt contract. Admission must refuse unrelated destination collisions before creating a relocation row.
