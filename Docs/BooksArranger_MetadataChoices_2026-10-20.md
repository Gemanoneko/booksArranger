- Question evidence signatures bind candidate ID, source fingerprint, relevant values and source/record provenance. Retrieval timestamps and retrieval order do not renew an unchanged conflict. - `metadata_choices.present` loads append-only decisions from the separate `metadata_choices` table. Each record retains actor/time, exact candidate revision/fingerprint, evidence signature, compared snapshots and explicit provider/corrected/unresolved answer. No choice establishes global provider preference. Corrected manual records are excluded from self-conflict only while their exact decision scope remains applicable; changed provider evidence asks again and includes the correction as another source.

Work selection does not combine one provider's title with another provider's author; missing identity fields remain missing. Provider/correction choices use existing `save(approve=False)` with private capture flags; only explicit corrected values are captured.
