### Bounded preflight limitation

The540s cumulative hash budget does not promise eventual progress for a single file requiring longer than that budget. Completed earlier verifications are durably reused on replan; an unfinished file has no completed proof and may repeat on an identical replan. Such a file remains explicitly verification_deferred, requiring corrected source throughput or a separately reviewed bounded per-file verification design. Deferred publications are never counted moved or fully handled. No deadline was extended and no resumable hash state was trusted across unprotected file lifetimes. Current live throughput/eligibility must still be measured through the admitted after-drain operation; no hypothetical NAS performance is asserted.
